# Resource attribution

World boundaries: Natural Earth, 1:110m Admin 0 – Countries.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Natural Earth map data are in the public domain: https://www.naturalearthdata.com/about/terms-of-use/

The bundled `world.js` contains simplified, projected geometry generated from this source. No external map request is made by the installed theme.

Komari: https://github.com/komari-monitor/komari (MIT).

Bundled flag SVGs are locally drawn geometric illustrations of public national flag designs.
