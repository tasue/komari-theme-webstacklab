# WebStackLab 全球监控大屏 · v1.2.2

为 Komari 1.6.x 制作的独立可安装主题。深蓝背景、青绿色地图、三栏运行态势布局，支持宽屏与手机。

## 安装

1. 登录 Komari 后台，进入「主题管理」。
2. 上传 `WebStackLab-Observatory-v1.2.2.zip`，安装后启用。
3. 刷新首页；可使用右上角全屏按钮，或浏览器 F11。
4. 后台主题菜单中的「大屏设置」可以修改标题、轮播间隔、资源阈值和地图位置。

安装包根目录包含 `komari-theme.json` 与 `dist/`，请直接上传，不要解压后再套一层文件夹。
原有主题仍可在主题管理中切换回来。此包只读取公开监控接口，不会修改节点、Agent、数据库、告警规则或远程控制设置。

## 功能

- 实时全局节点数、在线计算资源、总吞吐与今日流量。
- 健康、关注、危险、离线分布；健康判定综合资源占用和 Ping 丢包率。
- 左下角「网络探测质量」列出每个节点的延迟均值与丢包率，可切换公开 Ping 任务、点击节点联动右侧指标。
- 世界地图、节点聚合标记、选择联动和示意连接动画。
- 可搜索、按状态筛选的节点资源矩阵，包含 CPU、内存、网络速率、延迟均值和丢包率；点击节点切换右侧指标。
- 右侧默认显示全局 CPU 总核心、内存总容量、硬盘总容量和累计流量四块数字卡片；占用率另用进度条展示。
- 可切换单节点 CPU、内存、磁盘、每核心负载仪表；下方流量曲线随全局/单节点视图联动。
- 节点自动轮播、手动前后切换、暂停轮播、全屏。
- 优先使用 Komari WebSocket，失败后回退为 HTTP 轮询；断线重试。
- 无外部 CDN、字体、地图服务和管理员 API Key。

## 数据说明

- 节点基础资料：`GET /api/nodes`。
- 实时在线及指标：`WebSocket /api/clients`，按设定间隔发送 `get`。
- 回退：`GET /api/recent/:uuid`。最近上报超过 90 秒时判断为离线；如 Agent 自定义采集间隔很长，应优先确保 WebSocket 可用。
- 最近一小时上下行速率：`GET /api/records/load?uuid=...&load_type=network&hours=1`。服务端未启用指标记录时，曲线从打开页面起积累。
- 全局历史曲线使用公开 `public:queryMetrics`，将 `net.in.rate` / `net.out.rate` 按同一时间桶求和。
- 顶部「今日流量」通过公开 `public:queryMetrics` 查询 `traffic.up` / `traffic.down`，使用 `sum` 聚合服务器记录的流量增量，包含离线节点已有的今日记录。默认从北京时间（Asia/Shanghai）00:00 起算，每分钟刷新，跨日自动重置查询范围。后台可选择 UTC 或浏览器本地时区。仅统计服务端保存过的记录；启用监控前或未保存的流量不会补算，记录不可用时显示「—」，不会拿累计流量冒充今日流量。
- 集群健康根据最新 CPU / 内存 / 磁盘 / 每核心负载和最近一小时 Ping 丢包率计算，不是 Komari 的通知历史。资源默认关注阈值 80%、危险阈值 95%；丢包率默认关注阈值 5%、危险阈值 30%。
- Ping 任务来自 `GET /api/task/ping`，统计来自公开 `public:getPingMetricStats`。最近一小时每 30 秒刷新，延迟按成功探测次数加权，丢包率为失败次数 / 总次数。没有探测记录时显示「—」，不会显示为 0 ms 或 0% 丢包。地图上方、右侧性能总览和资源矩阵使用相同任务筛选口径。
- 右侧「累计流量」是已知节点上报的总上传与总下载之和，包含已获取过的离线节点计数，可能因 Agent 重启或网卡计数重置变化，不代表月账单流量。
- CPU 总核心、内存容量、磁盘容量及使用量均汇总当前在线节点。CPU 综合占用按各节点逻辑核心数加权，绝不是把多台机器的百分比直接相加。
- 私有站点需先登录；前端不会保存管理员密钥或 Agent Token。
- 页面时间按浏览器本地时区显示。
- 地区值同时兼容 ISO 二字母代码和国旗 Emoji。

## 地图位置

名称含已识别城市（例如上海、东京、洛杉矶、西雅图）时使用城市中心；其他节点使用地区参考点。
地图和连接线仅是地区与选中节点的示意，不表示精确物理位置或实际网络路径。
没有已知位置的节点仍显示在矩阵中，不会在地图上伪造位置。

可在「大屏设置 → 自定义节点位置」配置公开的地区示意坐标：

```json
{
  "你的节点UUID": {"lat": 31.23, "lon": 121.47, "label": "上海"}
}
```

配置公开可见，不要填写家庭精确坐标、IP、Token、密钥或私密备注。
既有主题自定义 CSS 不一定适配本主题；原先仅修改国旗的样式不会影响本主题的数据或地区定位。

## 演示与本地预览

- 正常首页只使用真实数据。接口异常不会自动替换成演示数据。
- URL 加 `?demo=1` 可显式进入演示模式，页面标注「演示数据」。
- 源码中的 `preview.py` 提供本地预览，只代理原站点的公开只读接口。该脚本不包含在主题安装包中。
- 修改源码后，打包 `komari-theme.json`、`dist/`、`preview.png`、`LICENSES.md` 即可。
- `analytics.test.cjs` 包含 CPU 加权、容量汇总、地区代码、午夜换日、今日流量增量、全局曲线和 Ping 丢包统计测试；可运行 `node analytics.test.cjs`。
